# People Photo QA Project Instructions

- Keep automatic outputs framed as image observations or visible impressions, not facts about health, personality, ethnicity, identity, or moral character.
- Do not add public-person or celebrity face embeddings as targets.
- Do not add sourcing, scraping, or closed-directory export workflows to the public repo.
- Keep raw photos, exports, cookies, runtime logs, SQLite files, and agent scratch state out of git.
- Remote VLM review must be opt-in, consent-gated, cached, and limited to the smallest useful image crop.
- Technical docs and code comments should stay in English.
